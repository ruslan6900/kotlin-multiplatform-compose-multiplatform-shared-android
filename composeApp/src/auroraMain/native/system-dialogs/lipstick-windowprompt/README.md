# Эксперимент с системными диалогами Авроры

`VpnWindowPromptTest.qml` и `MathVpnWindowPrompt.qml` — исследовательские
примеры для устройства в режиме разработчика. Системный процесс windowprompt
создаёт два окна `Sailfish.Lipstick.SystemDialog` поверх текущего экрана.

Для проверки на Авроре 5.2.1 вызывался внутренний D-Bus-метод
`com.jolla.windowprompt.showStorageDevicePrompt` с `componentName`, указывающим
на временный QML-файл. Этот метод предназначен для системных диалогов носителей,
доступ к нему с обычными правами был отклонён; в эксперименте использовался root.
Это не публичный API для стороннего VPN и не готовый механизм поставки.

`MathVpnWindowPrompt.qml` передаёт ответ на вопрос приложению по сессионной
шине D-Bus. В desktop-файле указан `ExecDBus`: если демо закрыто, RuntimeManager
запускает его бинарный файл с `--dialog-service`, без пользовательского окна.
Ответ `4` проверяется в приложении. Фоновый процесс завершается после одного
обработанного запроса. В единый development RPM включён системный
сервис из `boot/`: при включённой настройке и новой загрузке он запрашивает
показ окна; при выключенной настройке не показывает его.

Второе окно предлагает вызвать VPN-контроллер в приложении либо напрямую
`Connect` заранее созданного тестового профиля ConnMan. Оба пути проверяют
состояние ConnMan, а не считают сам ответ D-Bus подтверждением подключения.
На тестовом устройстве оба способа довели профиль до `ready`. Этот VPN-провайдер
только создаёт тестовый интерфейс и отбрасывает пакеты из тестовой подсети;
он не является защищённым VPN-туннелем.

Bridge и плагин были подписаны SDK-сертификатом, но тестовая установка системного
пакета потребовала разового обхода валидации состава RPM. Это не готовая схема
поставки. Системный диалог пока закрывает фон: даже настройка прозрачного QML
окна не обеспечила видимость рабочего стола на данном устройстве.

Не вводите в этот эксперимент секреты: UI выполняется в системном процессе,
а код не является механизмом для аутентификации.

Подробное описание: `docs/aurora-system-dialogs.md`; сборка и подпись: `docs/readme-chapters/05-aurora-specific.md`.
