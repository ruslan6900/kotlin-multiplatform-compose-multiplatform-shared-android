# Release 0.0.4 — Aurora KMP Demo

Development-релиз демонстрирует проверки сети и изменения времени, локальные и периодические уведомления, разовые и периодические фоновые задачи, а также экспериментальные системные диалоги и подключение тестового VPN через ConnMan.

В единый RPM для Aurora `aarch64` входят приложение, нативные задачи, тестовый VPN plugin и provider, D-Bus bridge, системные диалоги и службы. Версия 0.0.4-1 установлена на физическом устройстве, проверены целостность файлов RPM и запуск приложения. На предшествующей сборке 0.0.3-15 также проверены повторный запуск и переход тестового VPN в `ready`. Тестовый provider отбрасывает пакеты и не создаёт защищённый туннель.

Системный пакет предназначен только для тестирования: его штатная установка APM была отклонена проверкой состава; на тестовом устройстве применён разовый обход проверки, а приложение работает без Sailjail. Системные диалоги используют привилегированный внутренний интерфейс Lipstick. После сборки RPM подписывается отдельно тестовым сертификатом SDK `regular`; сама подпись не отменяет ограничений системного пакета. Подробности и команды: [сборка и подпись](readme-chapters/05-aurora-specific.md), [диалоги](aurora-system-dialogs.md), [уведомления и задачи](aurora-system-events.md), [сеть и время](aurora-network-and-time.md).
