# Граница общего и платформенного кода

В `commonMain` находятся модели, use case, Compose-экраны, навигация, Koin, repository-интерфейсы и Room schema.

Платформенные source set'ы отвечают за entry point, lifecycle, HTTP engine, путь к БД, файловые API, RPM-пакетирование и Aurora-сервисы.

VPN не является общим механизмом управления сетью: на Aurora он использует ConnMan и системные разрешения, а на других платформах возвращает состояние недоступности. Это предотвращает ложную переносимость системной интеграции.
