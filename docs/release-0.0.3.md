# Release 0.0.3

Релиз `0.0.3` превращает проект в проверочный стенд Aurora KMP с системной test VPN-интеграцией.

## Что вошло

- экран VPN с подробным журналом операций;
- системный D-Bus bridge между CMP-приложением и ConnMan VPN;
- тестовый ConnMan-провайдер: он создаёт `vpn0` для `198.51.100.0/24`, но не меняет DNS и маршрут по умолчанию;
- единый development RPM для приложения, bridge и test VPN-компонентов;
- журналы запуска UI и последовательных библиотечных проверок;
- русскоязычные комментарии к коду и актуальная документация по сборке, D-Bus и ограничениям sandbox в Aurora 5.2 emulator.

## Подтверждённая проверка

На development overlay Aurora 5.2 успешно выполнены: установка RPM, запуск приложения в `startDebug --nosandbox`, создание тестового профиля, переход в состояние `ready` и последующее отключение в состояние `disconnect`.

RPM для физического устройства по-прежнему требует доверенной подписи, которая не хранится в этом репозитории.
