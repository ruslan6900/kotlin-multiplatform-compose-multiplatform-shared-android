# Запуск на выбранной вкладке Aurora Device Manager

1. Установите собранный ZIP плагина в Android Studio и перезапустите IDE.
2. Откройте проект и вкладку нужного устройства в Aurora Device Manager. Для UTM в меню «+ → Управление устройствами → устройство → Настроить SSH для запуска приложений…» укажите проброшенный в UTM порт SSH, пользователя и ключ. Для физического устройства используются SSH-параметры его профиля.
3. Устройство должно работать и быть доступно по SSH; ключ хоста должен быть сохранён в `~/.ssh/known_hosts`. Запуск не отключает проверку ключа хоста.
4. В Run Configurations выберите `Aurora | Run on Active Device` и нажмите Run. Выбранная цель фиксируется при конфигурации Gradle до сборки: переключение вкладки во время сборки не перенаправляет установку или запуск.

Демонстрационный сценарий собирает RPM для aarch64, проверяет архитектуру подключённого устройства, устанавливает пакет и запускает приложение в debug-режиме без sandbox. Если устройство не выбрано, SSH не настроен или архитектура другая, запуск завершается с ошибкой. Доступ по USB сам по себе не настраивается: физическому устройству нужен рабочий SSH через сеть или USB-сеть. Обычные Run-конфигурации проекта остаются без изменений.
